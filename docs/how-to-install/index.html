Install the Digital Certificate

Purpose​

This guide provides PNPKI subscribers with detailed instructions on how to install their digital certificate on a computer. It ensures a smooth installation process, helping users securely set up their certificate for use in digital transactions and communications.

Procedure​

What You Need:
  1. Desktop or Laptop (Mobile phones are NOT recommended.)
  2. Digital Certificate (.p12 file) – Download Here
  • WINDOWS
  • MAC OS

Step 1: Open the .p12 file by double-clicking it.

Step 2: Select Current User as the store location, then click Next.

Step 3: Confirm the file to import by clicking Next.

Step 4: Enter the password you set during certificate download, then click Next.

Optional: Tick "Enable strong private key protection" if you want to require a password each time the certificate is used (e.g., for digital signatures).

Step 5: Keep "Automatically select the certificate store" checked, then click Next.

Step 6: Click Finish to complete the installation.

(Optional) Enable Extra Security
Only do this if you enabled "strong private key protection" in Step 4.

Step 7: Click Set Security Level...

Step 8: Select High ➡️ Click Next.

Step 9: Set a new password ➡️ Click Finish.

Step 10: Click OK to complete the setup.

Step 1: Open the .p12 file by double-clicking it.

Step 2: When prompted by Keychain Access, click Use Password...

Step 3: Enter your Mac login password, then click OK.

Step 4: In the "Add Certificates" dialog box, select "login" as the Keychain, then click Add.

Step 5: Enter the password you set during certificate enrollment, then click OK.

FAQs​

Where do I get the password for installing my digital certificate?

The password was set when you enrolled for a digital certificate.

Reminder: Keep your password in a secure place. Lost passwords cannot be recovered.

Can I install my digital certificate on a mobile phone?

Yes, but mobile devices do not currently support free apps for signing or encrypting with digital certificates. A desktop or laptop is recommended.

Can I install my digital certificate on multiple devices?

Yes, but you must manually install it on each device using the .p12 file and your password.

What happens if I lose my .p12 file?

If you lose your .p12 file, you must request a revocation of your current certificate before applying for a new one.

Steps:

  1. Contact the PNPKI team to revoke your lost certificate.
  2. Once revoked, you can enroll and download a new digital certificate.

Important: There is no way to recover a lost .p12 file, so keep a backup in a secure location.

How do I protect my digital certificate from misuse?
  • Keep your .p12 file in a secure location.
  • Use "Enable strong private key protection" during installation to require a password each time it’s used.
  • Never share your password with anyone.
