Install the Digital Certificate

Purpose​

This guide provides PNPKI subscribers with detailed instructions on how to install their digital certificate on a computer. It ensures a smooth installation process, helping users securely set up their certificate for use in digital transactions and communications.

Procedure​

What You Need:
  1. Desktop or laptop (Mobile phones are not recommended.)
  2. Digital Certificate (.p12 file)
  • WINDOWS

Step 1: Double-click on the Digital Certificate (.p12 file).

Step 2: Make sure Current User is selected for the Store Location then click on Next.

Step 3: On the File to Import section, just click on Next.

Step 4: Enter the password that was set during the Downloading of Digital Certificate then click on Next.

OPTIONAL

Tick on the Enable strong private key protection. to set up the device to ask for a password everytime a digital certificate is used on the device (e.g. signing digital documents).

Step 5: Leave Automatically select the certificate store based on the type of certificate selected and click on Next.

Step 6: Click Finish on the Certificate Import Wizard Completion window.

SET UP PASSWORD FOR DIGITAL CERTIFICATE

Do not do steps 7-10 if you have not ticked on the Enable strong private key protection. from Step 4.

Step 7: Click on the Set Security Level...

Step 8: Select High then click on Next.

Step 9: Enter a new password then click on Finish.

Step 10: Click on OK to complete the installation.

FAQs​

Where do I get the password for installation of digital certificate (.p12 file)?

This password is set when enrolling for a digital certificate.

NOTE: Please save all your passwords in a secure location.

Can I install the digital certificate on a Mobile Phone?

Digital Certificates can be installed on mobile phones but as of now,there are no free mobile apps that can use digital certificates for signing and encrypting.
