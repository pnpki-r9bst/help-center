Download the Digital Certificate

Purpose​

This guide provides PNPKI subscribers with step-by-step instructions to enroll and download their digital certificates. It aims to ensure a straightforward and secure process while adhering to PNPKI requirements.

Procedure​

What You Need:
  1. Desktop or laptop (Mobile phones are not recommended.)
  2. Internet connection

Step 1: Visit the Self-Service Portal.

Step 2: Login using the credentials emailed to you by the PNPKI system.

Step 3: Go to Enrollment → Certificate Enrollemnt.

Step 4: Click on RSA under Key Algorithm.

Step 5: Enter a password and click on Enroll.

Step 6: Go to Token / Certificate → Token / Certificate List.

Step 7: Search for your Certificate and click on View.

Step 8: Click on Download P12.

FAQs​

I can't login to the Self-Service Portal. It says You are not authorized to login. Please contact the administrator.

Make sure to copy the password with no extra spaces. If problem persists, contact r9.pnpki@dict.gov.ph.

I don't see the option to Download P12.

Check the Downloads folder. Contact r9.pnpki@dict.gov.ph if P12 file is missing.

tip

P12 file can only be downloaded ONCE.

I clicked on Download P12 but the I can't find the file anywhere.

There are instances where the P12 file is not downloaded when using Mobile Phones. Please use desktop or laptop for enrolling and downloading the digital certificate.

Contact r9.pnpki@dict.gov.ph if P12 file is missing.
